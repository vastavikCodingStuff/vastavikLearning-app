# Release Notes — Vastavik Computers v1.0.25

**Release Date:** September 4, 2026  
**Build:** v1.0.25 (Production Release)  
**Platform:** Android (minSdk 24, targetSdk 35)

---

## 🚀 Key Highlights in this Release

### 1. Mistral "GOD" AI Integration & Multi-Tier AI Hierarchy
- **Mistral is GOD (Default Engine):** Vastavik Learning now integrates Mistral AI as the primary default AI engine across all chat, doubt-solving, and practice generators.
- **Smart Dynamic Model Fallback:**
  1. Primary: `mistral-small-latest` (with automatic fallback to `ministral-8b-latest` / `open-mistral-7b` to prevent any rate-limit interruptions).
  2. Fallback 1: `Gemini 3.7 flash is Demi-god` (fast, capable backup).
  3. Fallback 2: `Gemini 3.6 flash is Human AI` (rock-solid baseline).
- **Thinking Tokens Disabled:** Thinking token overhead is strictly disabled across Gemini models (`thinkingBudget: 0` on 3.7 Flash and `thinkingLevel: "minimal"` on 3.6 Flash) for lightning-fast instantaneous response times.

---

### 2. Stylish AI Model Selector & Search Dialog
- **Top Bar Model Picker:** Replaced the static header text with a sleek, interactive Neo-Brutalist selector card showing the active model and badge.
- **Interactive Search & Selection Modal:** Tap the top bar to open a full-featured dialog with live search filtering:
  - 👑 **Mistral is GOD** — Amber badge, Supreme Coding Intelligence & Accuracy (Default).
  - ⚡ **Gemini 3.7 flash is Demi-god** — Blue badge, Ultra-low latency & deep reasoning.
  - 👤 **Gemini 3.6 flash is Human AI** — Emerald badge, High-throughput balanced assistance.
- Selection instantly switches the active engine for the chat session.

---

### 3. Rich CS Domain Sample Input Chips
- **Curated Prompt Quick-Starters:** Added a dedicated horizontal carousel of domain-tailored sample prompts when starting a new chat:
  - 💻 `Explain Code`
  - 📝 `Generate Quiz`
  - 🐛 `Find Bug`
  - 🗄️ `SQL Query`
  - 🔍 `Binary Search`
  - 🧱 `OOP Pillars`
- Tapping any chip immediately populates the chat input for seamless learning.

---

### 4. AI Chat Gestures & Drawer Redesign
- **Swipe Right to Practice:** Swiping towards the right on the AI Chat screen now seamlessly navigates directly back to the **Practice** screen. Swiping left continues to open the chat history sidebar.
- **Enhanced Chat History Drawer:**
  - **15% Wider:** Drawer width expanded to 55% of the screen for superior reading clarity.
  - **Floating Neo-Brutalist Frame:** Slightly reduced top and bottom heights with 22dp rounded left corners (`topStart` & `bottomStart`).
  - **Chat Deletion Support:** Every conversation in the history list now includes a dedicated delete button with instant local cache purging.

---

### 5. Admin AI Engine Logs Toggle
- **Controllable Floating Banner:** Added a toggle switch in the Admin Dashboard to enable or disable the bottom floating AI Engine diagnostic banner (`DebugLogBoxOverlay`).
- Admins can freely inspect raw JSON endpoints, active model parameters, and HTTP response traces without cluttering the normal student view.

---

### 6. Profile & Practice Screen UI Polish
- **Student Profile Theme Alignment:** Updated student notification button and header chat action chips to deep Royal Blue (`#2563EB`) matching the app theme.
- **Practice Content Attribution:** AI practice problem sets clearly display `"Auto-generated by VastavikAI"`.
